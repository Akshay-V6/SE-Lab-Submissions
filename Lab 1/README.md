# Lab 1: Requirements Engineering

Submission artifacts for the requirements engineering lab, using the handout's
coffee ordering example as a campus self-service coffee kiosk.

## Deliverables

- [Requirements table](requirements_table.docx): five functional and two
  non-functional requirements, including measurable acceptance criteria.
- [UML use-case diagram](use_case_diagram.pdf): customer, barista, store admin,
  and payment gateway actors, with include relationships.
- [Use-case flow](use_case_flow.docx) ([PDF](use_case_flow.pdf)): main success
  path and alternate flows for unavailable items and declined payment.
- [Editable diagram source](use_case_diagram.puml).

The handout does not specify a separate project scenario, so the coffee kiosk
example is used. The handout's peer review activity requires a classmate; peer
review comments remain pending.
